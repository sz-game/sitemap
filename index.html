Fast Sitemap Crawler

A browser bookmarklet that crawls same-origin links from the website currently open in your browser, then downloads an XML sitemap.

Step 1 — Add the crawler to bookmarks

Drag this green link to your Chrome bookmarks bar. If the bookmarks bar is hidden, press Ctrl + Shift + B.

Fast Sitemap Crawler

Don't simply click this link while viewing this local HTML file. Drag it to the bookmarks bar first.

Step 2 — Crawl your website

  1. Open your website's homepage in Chrome, for example https://yourdomain.com/.
  2. Click the saved Fast Sitemap Crawler bookmark.
  3. Enter a page limit when prompted (maximum 50,000).
  4. Wait for the progress panel. The browser will download sitemap.xml when finished.
  5. Review the XML before uploading it to your site's root directory.

Important limitations

  • It only crawls the same origin as the currently open page. Open the correct domain first.
  • Keep the website tab open while it works. It uses your browser and network, not a background server.
  • It cannot reliably discover JavaScript-only links, pages requiring login, orphan pages not linked from crawled pages, or URLs blocked by the site.
  • This basic bookmarklet does not fully parse robots.txt or split large sitemaps into an index. Do not publish blindly; validate the generated XML and follow the site's crawl policy.
  • For large sites, very high page limits may take time or be interrupted by the browser.

Only use it on websites you own or are authorized to crawl. The bookmarklet runs code in the open website's page context.

This tool requires no command prompt, local server, or installed packages.
